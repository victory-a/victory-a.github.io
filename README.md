# Victory Asokomeh — Portfolio

Vue 3 + Vite + TypeScript personal site.

```bash
npm install
npm run dev
npm run build
```

## Deploy to GitHub Pages

Published from `docs/` on `main` at [victory-a.github.io](https://victory-a.github.io).

```bash
npm run build:pages
git add docs && git commit -m "Deploy site to GitHub Pages" && git push
```

Then set **Settings → Pages → Source** to `main` / `/docs`.
